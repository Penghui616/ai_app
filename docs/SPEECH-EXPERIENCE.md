# 语音识别体验：百炼后端接入

入口：应用选择 → 应用体验 → 语音识别体验，或 `/#/speech`。

## 当前能力

- 普通话、英语、自动识别语言；没有粤语入口或粤语朗读材料。自动识别使用模型自身的多语言能力，并非仅限中英文。
- 真实录音、计时、音量、停止与试听；上传 WAV、MP3、M4A、OGG、WebM。单段 60 秒、原文件 20 MB 上限。
- 点击开始识别后，经平台后端调用百炼 `qwen3-asr-flash`，展示原始转写文字、音频时长及处理耗时；不让文字模型润色，不发送参考朗读材料。
- 状态检查、未配置提示、繁忙/权限/网络/超时/格式错误提示。清空结果保留音频，重置或离页清除当前页面数据并丢弃迟到结果。
- 静音检测只过滤极低幅度音频，不是通用人声检测器；音乐/噪声仍可能得到转写，不能当发音评分。

## 配置与启动

本机已经安装 `imageio-ffmpeg==0.6.0`。其他机器在项目根目录执行：

```powershell
.\backend\.venv\Scripts\python.exe -m pip install -r backend/requirements-speech.txt
```

运行时复用 `backend/.env.agent` 的 `DASHSCOPE_API_KEY` 与 `AGENT_BASE_URL`，不改变助手模型。ASR 模型固定为 `qwen3-asr-flash`。可选 `SPEECH_API_KEY`、`SPEECH_BASE_URL` 覆盖语音配置（放在现有助手配置文件或进程环境）；没有独立语音配置时回退到助手配置。只允许官方中国内地 HTTPS 兼容接口，状态响应不包含密钥或连接地址。

开发后需要人工重启现有后端，再刷新 `http://127.0.0.1:5173/#/speech`。若有训练任务，先等待训练结束。重新检查按钮用于刷新配置状态；更改配置仍需重启服务。状态“可用”表示本地配置和转换组件齐备，不保证账户额度或上游授权始终有效，实际调用错误会原样分类为安全提示。

本轮没有启动或重启正式后端，没有访问公司数据库。新增服务不依赖数据库、不下载本地 ASR 模型、不需要 GPU。

## 接口与处理

- `GET /api/speech/status`：配置与解码器状态、模型、语言、大小/时长上限、是否繁忙。
- `POST /api/speech/transcribe?language=zh|en|auto`：请求体为音频二进制，Content-Type 为相应音频 MIME。只接受上传内容，不接受远程音频 URL。
- 返回 `text`、`durationSeconds`、`elapsedMs`、`model`、`noSpeech`、`notice`。`elapsedMs` 包含转换和百炼请求，不包含浏览器上传时间。
- 后端重新检查长度、输入格式和解码后时长。FFmpeg 将音频转为 16 kHz 单声道 16-bit WAV，60 秒约 1.92 MB，Base64 后约 2.56 MB，低于百炼文档中的 10 MB 限制。
- 解码超时 15 秒，上传超时 15 秒；百炼连接超时 10 秒、读写超时 60 秒；前端总等待上限 100 秒。录音停止事件允许最多 0.25 秒计时误差，再裁到 60 秒。
- 单进程同时处理一个请求，每分钟最多 10 个受理请求，超出返回 429。不自动重试付费识别。未部署分布式限流，也未进行课堂并发验收。
- 浏览器取消或离页只停止等待；已经发给百炼的调用可能继续并产生费用。后端保持任务名额直到实际结束，避免取消后重入并发。

## 数据处理边界

页面会说明音频发送至阿里云百炼。原文件只在本地临时目录解码，正常完成、转换失败和超时会清理；不保存音频历史或转写内容到数据库，不在日志输出密钥、音频和转写内容。云服务的数据处理按其条款执行，本项目不声称云端零保留。API 密钥不会发给浏览器。

平台目前沿用本地开发访问方式。若对外发布，还需统一用户鉴权、账户级额度及多人负载验证；单进程限流不是公开云平台的完整计费防护。

## 验证结果

- 新增 28 项语音隔离后端测试通过，涵盖 WAV/MP3/WebM/OGG/M4A 的真实 FFmpeg 转换、清理、静音、超限、无效文件、接口、语言参数、上游错误脱敏、请求频率、忙碌与取消后名额保持。
- 原有 76 项助手回归已通过；语音接口测试中的百炼响应用替身提供，不等同于真实识别质量。
- 前端类型检查、生产构建及 21 项浏览器交互检查通过，覆盖真实浏览器录音与试听（模拟设备）、接口提交、错误恢复、空文本和取消后的过期响应。接口响应用替身提供。
- 真实百炼验证：两段 Windows 合成语音，经新接口转换并调用 `qwen3-asr-flash`。普通话 4.953 秒，耗时约 750 ms；英语 5.169 秒，耗时约 625 ms。两段返回文本均与预期一致。样例由程序生成，不读取学生录音或公司项目。不是儿童、教室噪声、真实麦克风或并发效果的证明。
- 后端重启后的正式页面与真实麦克风需要人工试用。本轮没有新建 Git 提交或推送。
