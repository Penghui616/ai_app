# 图像分类实验辅导助手 v0.7

## 使用与配置

1. 现有 MySQL 配置继续使用 backend/.env，本次不更改连接或账号。
2. 双击项目根目录「配置实验助手.cmd」。从百炼控制台复制中国内地业务空间的 OpenAI 兼容 Base URL；填写模型 qwen3.8-max 和 API Key。密钥在本机隐藏输入。
3. 配置保存在 backend/.env.agent，已被 Git 忽略；不要上传或发送这个文件。工具只保存配置，不发送模型请求、不连接数据库。
4. 停止旧后端并重新运行「启动后端.cmd」，刷新页面，在实验助手中点击「重新加载」。配置完整不等于已验证模型权限：首次真实提问成功后才能确认连通性。
5. 助手新增的两张表为 vl_agent_threads、vl_agent_notes。启动时仅在已授权的 vision_lab_dev 内创建缺失表；如果数据库名不同，助手存储保持不可用，需单独确认授权后调整。测试使用显式注入的临时 SQLite，不回退生产运行数据库。

百炼地址示例（以控制台实际提供的地址为准）：
- https://你的业务空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1
- 旧地址 https://dashscope.aliyuncs.com/compatible-mode/v1 也在允许列表内。

## 第一版范围

- 图像分类实验页面提供基础／进阶切换。请求中只传一个 mode，后端以系统提示约束当前回答；切换不会生成第二份回答或重写历史。实际语言表现需要真实模型验收。
- 六个只读工具：实验状态、操作指南、训练列表、训练详情、两次训练对比、文件测试记录。工具执行始终绑定已经过权限校验的当前项目，不接受任意项目 ID 或 SQL。
- 快捷按钮预先执行固定查询，自由问题由模型按需调用工具。每次最多 4 轮模型请求、6 个工具调用；详情才提供完整曲线（最多 100 轮），默认摘要。
- 沿用 HTTP 协议适配层（httpx）调用百炼兼容接口，未引入 LangChain / LangGraph 或额外模型 SDK。新应用可以复用调用、对话存储和权限部分，但需要独立工具。
- 只发送文字：学生问题、必要历史、笔记、项目名称和类别数量、工具返回的参数及指标。不上传样本、测试图片或摄像头画面，不传数据库凭据、图片路径和 API Key。
- 不提供自动训练、修改参数、删除实验、联网搜索、代码执行、视觉诊断和模型导出。

## 对话与项目记忆

每个项目最多 20 个对话，每个对话最多 100 轮。完整消息与证据、token 用量存在后端，最近 6 轮进入模型上下文。更早部分保留最多 2000 字符的最近历史摘录，不是永久完整语义摘要；需长期保留的想法应存为项目笔记。

项目笔记最多 30 条，每条最多 600 字符；最近 8 条在新问题中提供给模型。笔记必须由学生填写或从回答中编辑确认后保存，类型为学生反馈、待验证结论、待办实验，统一标记未核验。新建／删除对话不删除笔记，删除项目时同事务清除该项目助手表记录。

工作区仍使用 HttpOnly cookie 隔离，没有正式学生账号。清除 cookie 后无法找回对应数据；此版本没有跨项目学生学习档案。多实例运行和公共课堂部署需要另行完善身份、配额、队列及会话锁。

## 状态与证据

- 数量、模型是否有效、缺少步骤由程序计算；助手负责解释。
- 摄像头或文件识别成功后，浏览器在 sessionStorage 记录当前项目对应的模型 ID。该状态是浏览器报告，只用于操作指导，不代表识别正确。新模型不会沿用旧模型已测试状态。
- 文件测试记录没有正确标签和原始图片，因此工具明确返回 accuracyAvailable=false，不能将预测分数当实际准确率。学生纠正作为反馈保存，不当作已验证标签。
- 训练对比检查数据版本、训练与验证样本集合是否相同；汇报差异不等于证明因果。
- 每个回答可展开查看工具数据快照及实际 API 返回的 token 用量。回答期间实验变化时显示提示，历史快照不会伪装成最新数据。

## 失败、限制与费用

未配置时显式提示，不使用旧版演示回复充当 AI。外部调用失败不修改实验数据，不保存半个问答；前端保留问题供重试。模型最多输出 1600 tokens，关闭思考模式；每次请求最多 90 秒的总执行预算（HTTP 超时按剩余预算设置），每个工作区每分钟最多 8 次。

模型服务遇到限流、502、503 最多自动重试一次。请求可能已在服务商侧产生费用，即使界面最终报错；失败日志记录已返回的 usage，网络中断时无法获知完整计费用量。不要把应用计数当作服务商账单。

## v0.7.1 实验编号与曲线读取修复

- 页面与助手统一：第 1 次是最早的训练，失败和取消也占编号；新到旧的列表不会改变编号。项目当前没有单条训练删除功能。
- 每次提供最近 12 条轻量索引（编号、ID、状态、参数），并补入问题明确提到的更早编号；列表工具支持 offset 翻页，不默认返回曲线和指标。
- “分析第五次实验的曲线”“第5次”（承接上一条曲线问题）由程序预先读取对应曲线，再交给模型解释，避免模型直接拒绝查询。
- 详情工具同时支持 run_number 或 run_id。复杂或有歧义的自由语言仍由模型结合索引调用工具，不保证所有表达都命中程序规则。
- 修复验证使用隔离测试库和模型替身。更新后需重启后端；不会自动重启运行中的训练或修改公司数据库。
